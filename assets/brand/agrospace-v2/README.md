# AgroSpace logo · originals

Vector originals of the AgroSpace logo: an astronaut with an opaque visor and a straw hat, with a
three-tine pitchfork beside it, and the name **agrospace**.

| File | What it is |
|---|---|
| `agrospace-logo.svg` | Full logo (symbol + name), static, transparent, no fonts or embedded images |
| `agrospace-symbol.svg` | The astronaut with the pitchfork, without the name |
| `agrospace-flow.svg` | Animated logo (2.1 s intro, gentle float, waves on hover or keyboard focus); vectors and CSS only, no scripts |
| `agrospace-preview.png`, `agrospace-symbol.png` | Renders of the static SVGs |

Animated and raster exports (transparent PNG, GIF, APNG, WebP, 1100 × 320) are in
[`assets/logo/agrospace/`](../../logo/agrospace/); the web app uses its own copies in
[`app/public/brand/`](../../../app/public/brand/).

**Colours:** green `#103B2D`, straw `#F4BA38`, ivory `#FFF3DA`. The name is Montserrat ExtraBold
converted to paths, so no font is needed. The animated SVG honours `prefers-reduced-motion`.
Do not stretch, recolour or add shadows to the logo.
